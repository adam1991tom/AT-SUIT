# Getting started

From buying to your first show in five steps.

1. **Get a licence key.** [Create an account](/register?next=/account) and start the free 30-day trial, or [choose a plan](/pricing). Your key appears under **Licence key** in [your account](/account) and arrives by email.
2. **Get a server.**
    - *Managed hosting*: we set up your server and email you a setup link. Skip to step 3.
    - *Your own server*: install AT SUITE with one command ([guide](/docs/self-hosted-install)).
3. **Run the setup wizard.** Open your server's address, enter the organisation, the venue, the rooms (one per line) and the first admin account, then paste the licence key.
4. **Add your people and laptops.** Add accounts for managers in **People**. Techs on an enrolled laptop just type their name each day. Install the [laptop app](/docs/laptop-app) on each tech laptop.
5. **Pair the screens and run the pre-show check.** Point each stage screen at its timer page, or pair it by code, then run the health check on the dashboard before doors open.

Stuck? [Message support](/contact?kind=support).
