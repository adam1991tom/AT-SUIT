Features

Everything a show day needs

Every plan includes every feature. Plans differ only by how many laptops can connect.

Show timers

  • Room timers with GO, pause, next and previous, plus or minus a minute, blink and blackout
  • A cue list with times, notes, overtime rules, and import from Ontime
  • One-tap quick timers and messages to the stage
  • Views for stage, minimal, clock, backstage, speaker preview and a transparent overlay for OBS or vMix, plus your own uploaded views
  • The timer keeps running on the laptop if the network drops

Crew chat, help and handovers

  • Chat for all crew and for each room, with files, emoji and priority messages
  • A Help button that rings the right people, then escalates if nobody answers
  • Handover notes so the next shift knows what happened
  • Tech passwords set by admins, with a forced change at first sign-in
  • An AI tech guide with show-day fixes, which can run privately on your own server

Live captions, kept private

  • Speech recognition runs on the tech's laptop, offline, from its microphone
  • A vocabulary list for names and jargon, plus live corrections
  • Audience caption screens, a subtitle bar, and a transparent overlay for streams
  • Transcripts are encrypted, exportable and deleted after 12 hours by default

Captions are automatic and can be wrong. For a deaf attendee who relies on them, book a professional captioner as well.

Laptops, screens and the venue

  • The Windows tech app: each tech's workspace, with layouts they can arrange
  • Laptop health and what each one is showing (off by default; never saved)
  • Screens paired by code, with test patterns: colour bars, gradients, LED tile map, sharpness and overscan
  • A venue dashboard, a pre-show health check, and PDF show reports
  • Presenter pages for slides, review notes and check-in, with no account needed
  • Bitfocus Companion module and a REST API for automation
  • Backups, room locks, roles for admins, managers and techs, and an audit log
