Downloads

AT SUITE needs a licence key to run. Start a free trial or choose a plan, and your key will be in your account.

Server (Linux)

On a fresh Ubuntu or Debian server, as root. It installs Docker if needed, then the newest release:

curl -fsSL https://github.com/{{ s.releases_repo }}/releases/latest/download/get.sh | sudo bash

Then open http://SERVER-IP:8080/, follow the setup wizard and paste your licence key. More in the install guide. With managed hosting you don't need this; we send you a setup link.

Laptop app (Windows)

Each tech laptop runs the AT SUITE app. Download the Setup .exe from the latest release, install it and enrol the laptop with your server (how). After that, laptops update themselves from your server, so they always match it.
