How it works

A small server, and laptops that do the work

The server keeps everyone in sync. Each laptop runs its own timer and captions, so nothing on stage depends on the network.

The AT SUITE server

We host it, or it runs on your own Linux server. It holds:

  • chat and help calls
  • the list of laptops and screens
  • accounts and passwords
  • your licence
  • updates for the laptop app
  • the tech guide and AI helper

Each tech laptop

It runs the AT SUITE Windows app, and:

  • runs the room timer and drives the stage screens
  • makes captions from its own microphone, offline
  • keeps working if the network drops, then catches up
  • reports its health to the server, if you turn that on

Getting started

  1. Choose a plan, or start a free trial. Your licence key appears in your account and arrives by email.
  2. Get a server. With managed hosting we set it up and send you a setup link. To run your own, install it with one command (guide).
  3. Run the setup wizard. Name the venue, add the rooms and people, and paste the licence key.
  4. Install the laptop app on each tech laptop and enrol it once. Techs then pick their room each day.
  5. Pair the screens by typing the code each one shows. You're ready for the show.
