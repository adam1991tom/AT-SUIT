# Running the show

## Before doors: the tech checklist
Keywords: pre show, checklist, before doors, line check, tech check, start of day, setup
1. Power on in order: sources and desks first, amps and speakers last (switch off in the reverse order).
2. Line check every mic and playback source at show level, with fresh batteries in every radio mic.
3. Check every screen, the confidence monitor and the speaker's timer.
4. Open every presentation and play every video with sound.
5. Test comms with the stage manager and the rest of the crew.
6. Run the AT-SUITE pre-show check on the console and fix anything it flags.

## Comms between crew
Keywords: comms, radio, headset, intercom, clear-com, channel, walkie talkie, calling cues
1. Keep messages short: say who you're calling, then the message ("Sound, from stage: next speaker's mic on").
2. Answer with "go ahead" when called, and confirm cues back.
3. Agree who calls the cues (usually the stage manager) and use standby and go.
4. Keep the show channel clear; use another channel for anything else.
5. Use AT-SUITE room chat for anything that doesn't need to be said out loud.

### Ask everyone: Is everyone's comms down, or only one person's?
- Everyone: See "Intercom (comms) down". Use radios or the AT-SUITE room chat for cues until it's back.
- One person: Their beltpack or headset: check it's on, the headset is fully plugged in and the channel is right, then swap the headset and the beltpack.

## Calling cues
Keywords: cue, standby, go, running order, script, cue sheet, caller
1. Give a standby before every cue ("Standby sound cue 5, video cue 3"), wait for each department to answer, then "Go".
2. Never say "go" in a sentence that isn't a cue.
3. Keep the running order and cue sheet up to date, and print a copy in case screens fail.

## Running order and timings
Keywords: running order, rundown, schedule, agenda, timing, cue list, ontime
1. Build the running order in the AT-SUITE timer as a cue list, with each session's duration.
2. Set an end action on each cue (stop, load next or play next) to match how the show runs.
3. Note real start and end times as you go; the show report keeps the timer runs.

## Voice of God announcements
Keywords: vog, voice of god, announcement, house rules, phones off, welcome
1. Record or script the announcements in advance (welcome, phones on silent, fire exits, back from break).
2. Play them at a level just above the room, on their own channel.

## Break and walk-in
Keywords: break, walk in, walk out, holding slide, music, lunch, interval
1. Put up the holding slide or a countdown timer, and play the walk-in music.
2. Use the timer's quick timers for the break countdown on the stage and foyer screens.
3. Give a 5 minute call before the session restarts.

## Rehearsal
Keywords: rehearsal, tech run, dry run, stagger through
1. Rehearse every changeover, video, mic swap and transition, not only the talks.
2. Note every problem and who owns the fix, and check each one before doors.
3. Save the desk, lighting and switcher settings at the end of rehearsal.

## Backups
Keywords: backup, redundancy, spare, plan b, failover
1. Have a backup for everything the show can't run without: a second playback laptop with the same files, a spare mic, spare cables and adapters, spare batteries.
2. Mark which AT-SUITE laptop is the Main PC and which is the Backup PC in each room.
3. Know how you will switch to the backup, and practise it.

## Show report
Keywords: show report, incident report, notes, end of day, handover
1. Write down what went wrong, what was done, and anything the next crew needs to know.
2. AT-SUITE's show report collects timer runs, help calls and stage messages for each room; add handover notes for the next shift.

## Intercom (comms) down
Keywords: intercom down, comms down, headset dead, beltpack, clear-com, clearcom, riedel, partyline, can't hear stage, no comms, talkback
1. Check the beltpack is on, the headset is fully plugged in, and the channel and volume are right.
2. Wired partyline runs through each beltpack: one bad cable can stop everything after it.
3. Wireless: a charged battery, registered to the base station, and in range.
4. While it's down, use radios or the AT-SUITE room chat for cues, and tell the stage manager.

### Ask everyone: Is it everyone's comms, or only one person's?
- Everyone: Check the main station is on with its channels on, then the cable or antennas from it. Use radios or room chat until it's back.
- One person: Their beltpack or headset: swap the headset, then the beltpack, then the cable to it (on wired comms).

## Run of show basics
Keywords: run of show, running order, show flow, rundown, show running, script, who does what, show caller
1. One running order everyone works from: times, sessions, speakers, and the cues for sound, video and lights in each.
2. One person calls the show (usually the stage manager); departments answer standbys and go on "go".
3. Before each session: the speaker's mic on and checked, their slides on preview, the timer loaded, walk-up music ready.
4. Note what really happened (late starts, overruns, faults) as you go, for the show report.
