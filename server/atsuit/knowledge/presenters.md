# Presenters, slides and laptops

## Presentation won't open or looks wrong
Keywords: file won't open, fonts missing, layout broken, pptx, keynote, google slides, pdf
1. Open every presentation on the show laptop at check-in, not when the speaker walks on.
2. Missing fonts change the layout: install them, or ask for a version with fonts embedded (PowerPoint: File → Options → Save → Embed fonts).
3. Keynote files: export to PowerPoint or PDF in advance if the show machine is Windows.
4. Google Slides: download as PowerPoint or PDF so it works without the internet.
5. Always keep a PDF copy as a backup.

## Clicker (presentation remote) not working
Keywords: clicker, remote, slide advancer, next slide, presenter remote, pointer
1. Check its USB receiver is in the show laptop and the clicker's battery is good.
2. Click on the slide show once so it has the keyboard focus (pop-ups and notifications steal it).
3. Long venues: use a long-range clicker or a receiver on a USB extension near the stage.
4. Keep a spare clicker, and a tech ready to advance slides on cue.

## Laptop going to sleep or showing notifications
Keywords: sleep, screensaver, notifications, pop up, do not disturb, updates, focus assist, lock screen
1. Set the show laptop to never sleep on mains, and turn off the screensaver.
2. Turn on Do Not Disturb or Focus (Windows) / Focus mode (Mac) so no pop-ups land on the screen.
3. Pause Windows Update and app updates for the show day.
4. Close email, chat and anything that might pop up; sign out of personal accounts.

## Presenter brings their own laptop
Keywords: own laptop, guest laptop, mac, usb-c, adapter, switching laptop
1. Have every common adapter ready: USB-C, HDMI, mini DisplayPort, and a USB-C charger.
2. Connect and test it in the break before their session, with sound, video and their clicker.
3. Set their display to 1920 × 1080 and Duplicate (or Extend for presenter view).
4. Ask them to turn off notifications and plug in their charger.

## Last-minute slide changes
Keywords: new version, changes, updated slides, latest file, version control
1. Agree a cut-off time for changes and one person who hands files to tech.
2. Name files clearly: session, speaker, version (for example "S3 Smith v3"), and delete old versions from the show laptop.
3. Open the new file and check it right away.

## Speaker changeover
Keywords: changeover, between speakers, swap, next speaker, walk on, walk off, handover
1. Have the next speaker mic'd and their slides ready on preview before the current one ends.
2. Use a holding slide, the walk-up music and the voice of God announcement to cover the change.
3. Brief the speaker on where to stand, where the confidence monitor and timer are, and how the clicker works.

## Speaker overrunning
Keywords: overrun, running late, wrap up, time up, timing, over time
1. Use the timer's warning and danger colours so the speaker sees it coming, and send a "Please wrap up" message to their screen.
2. Agree with the stage manager or producer before the show who decides to cut, and how (message, walk-on, music).
3. Use Blink on the timer or a flashing message as the last signal.
4. Tell the stage manager how much time the overrun cost so the running order can be adjusted.
