Welcome to AT-SUITE

This sets up the server for your venue. Everything here can be changed later in the console under Settings.

Rooms

One room per line. Each room gets its own chat, timer and captions.

Administrator

The first account. It can add techs and other admins.

Licence

Paste the licence key from your supplier. AT-SUITE works once a valid key is in.

No key yet? You can finish setup and add it later in Licence, but nothing else works until you do.
